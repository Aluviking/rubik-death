# Rubik Death · Distribuidor oficial de 911 by GFO Beer

Sitio vitrina de Rubik Death, distribuidor oficial en Bogotá de la cerveza artesanal **911 by GFO Beer**.

Sitio estático (HTML, CSS y JS sin dependencias de compilación) con una lata 3D interactiva en Three.js.

## Ver en local

```bash
python -m http.server 5500
```

Luego abre http://localhost:5500.
